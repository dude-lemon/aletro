# Security

## Reporting a problem

If you find a security problem in this plugin or in the Aletro service at aletro.dudelemon.cloud, please report it privately:

- On GitHub, open the **Security** tab of this repository and choose **Report a vulnerability**, or
- Write to us at [dudelemon.com/contact](https://dudelemon.com/contact).

Please don't open a public issue for a security problem. We reply within three working days and keep you updated until it is fixed.

## What this plugin contains

The plugin holds only instructions for Claude (the skills), its manifest and the address of the Aletro connector. It runs no code on your computer and asks for no keys. Claude reaches Aletro only after you sign in and allow it, and you can end that access at any time from Settings at aletro.dudelemon.cloud or from your Claude connector settings.
